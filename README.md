## 🎩 Introduction

**AgroTech Smart Farming** is a full-stack, scalable application designed to revolutionize the agricultural sector. By leveraging modern web technologies and Artificial Intelligence, the platform assists farmers in making data-driven decisions. From identifying crop diseases using AI to keeping track of daily finances and government schemes, this app is a complete toolkit for modern farming.

## ✨ Key Features

| Module | Features |
| :--- | :--- |
| **🩺 Crop Doctor** | AI-powered crop disease detection system to identify issues instantly. |
| **🤖 AI Chat Assistant** | Interactive AI Chatbot to answer farming queries and provide guidance. |
| **📒 Kisan Khata** | Smart digital ledger for farmers to track daily expenses and income. |
| **🌦️ Weather Alerts** | Real-time weather forecasting to plan farming activities effectively. |
| **📜 Govt Schemes** | Up-to-date information on agricultural government policies and schemes. |
| **💳 Subscriptions** | Razorpay integrated subscription models for premium features. |

## 🛠️ The Tech Stack

- **Frontend:** `React.js` + `Vite` + `TypeScript`
- **Styling:** `Tailwind CSS`
- **Backend & Database:** `Supabase` (PostgreSQL, Auth, Storage)
- **Payment Gateway:** `Razorpay`
